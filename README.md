# Progressive Overload Workout Tracker

Description:
This project is a GUI workout tracker built with Python. Users can log workouts, track weekly goals, compare past workouts, and receive progress suggestions.

Language Used:
Python

Libraries Used:
Tkinter

Features:
- Add and save workouts
- Track workout progress
- Weekly goal tracker
- Workout comparison system
- Progress suggestions
